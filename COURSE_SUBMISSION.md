# Финальная сдача коммерческого проекта

## Тип работы

**Коммерческий проект**

## Название

**ИИ FAQ/RAG-ассистент для сайта vassian.ru**

## Краткое описание

Проект предназначен для автоматической первичной консультации посетителей сайта по услугам, реализованным кейсам, формату работы и типовым вопросам. Ассистент отвечает на основании собственной базы знаний и сохраняет контекст многоходового диалога.

## Что реализовано

- системный промпт с ролью, стилем общения, ограничениями и правилами работы при отсутствии информации;
- собственная база знаний;
- RAG-поиск по базе знаний на FAISS;
- сохранение контекста многоходового диалога;
- обработка уточняющих follow-up вопросов;
- защита от выдумывания неподтверждённых цен, сроков, гарантий и других фактов;
- application-level guard для прямых запросов на раскрытие системных инструкций и внутреннего RAG-контекста;
- веб-интеграция ассистента с сайтом;
- инструкция по обновлению базы знаний и переиндексации;
- набор контрольных сценариев для тестирования поведения промпта.
